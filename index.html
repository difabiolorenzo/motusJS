    Méthode de recherche

    Merci à @Schraf d'avoir utilisé MotusJS comme support de sa vidéo JavaScript : Créons un outil pour résoudre le jeu de lettres MOTUS.

    Ses filtres sont repris dans la page Aide. Dans la console, les dictionnaires complets sont dans game.dictionnaire_verification une fois chargés (en jouant avec des mots de cette longueur, ou en ajoutant un mot de cette longueur dans les paramètres). Exemple :

    game.dictionnaire_verification.length_8
    .bienPlacees("EC......")
    .malPlacees(",L,EIA,CI,L,ILE,,")
    .exclure("TONPSXUFH")
