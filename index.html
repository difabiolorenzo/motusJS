Aide

Chercher les mots possibles

Recopiez ce que montre la grille : la recherche parcourt le dictionnaire des mots acceptés.

    Raccourcis clavier

    • Valider le mot : Entrée
    • Effacer une lettre : Effacer (←)
    • Nouvelle ligne : & / 1
    • Lettre bonus : é / 2
    • Supprimer la ligne : " / 3
    • Remplacer la ligne : ' / 4
    • Changer l'équipe qui a la main : ( / 5
    • Changer de grille (mots / numéros) : - / 6
    • Nouveau mot : ç / 9
    • Afficher la solution : à / 0
    • Son du temps écoulé : $ (¤)
    • Retour au menu / reprise de la partie : Échap
    • Avec « Confirmer chaque mot » : Entrée, puis & / 1 pour confirmer ou Effacer pour annuler

    Méthode de recherche

    Merci à @Schraf pour l'utilisation de MotusJS comme support et pour ces explications Javascript dans sa vidéo JavaScript : Créons un outil pour résoudre le jeu de lettres MOTUS

    Avec les modifications apportées, allez dans la console. Les dictionnaires complets sont stockés dans game.dictionnaire_verification après les avoir chargés (en jouant avec les mot de x lettres ou en ajoutant un mot de x lettre dans les paramètres)

    Example d'utilisation : game.dictionnaire_verification.length_8.bienPlacees("EC......").malPlacees(",L,EIA,CI,L,ILE,,").exclure("TONPSXUFH")
